Which features should we add?

Select everything that appeals to you — we'll scope down later if needed. The core fixes (phase accuracy, SimBrief ID/username, FMC button removal, map embed, Submit Position Report) are already in regardless.

⏱

Live Zulu Clock

Always-on UTC clock ticking in the status banner. Pilots always need the time and it gives the page an "alive" feel even on the ground.

⛽

Fuel Burn Rate & Endurance

Current fuel flow (lbs/hr), time remaining at current burn, and planned vs actual fuel comparison if OFP is loaded. Shows as extra rows in the instrument grid.

📋

ACARS Flight Event Log

A timestamped log of key events: engines started, takeoff, TOC reached, TOD, approach, touchdown. Shows below the main panel so you can see the flight's history at a glance.

🔔

Phase Transition Alerts

A subtle toast/banner when a major phase changes — e.g. "Cruise reached · FL350" or "Descending · TOD". Helps catch the tracker working correctly without staring at it.

🔧

Expanded Engine Data

Add fuel flow per engine and OAT/SAT/TAT alongside N1. Particularly useful for long-haul step climbs and catching abnormal engine behaviour.

📡

Squawk Code from OFP

Parse the squawk code from the SimBrief OFP and display it in the flight plan card. Small but feels very professional — pilots always need to look this up.

📄

Full OFP Text Viewer

Collapsible section showing the raw SimBrief OFP text (the full operational flight plan document). Pilots who do proper pre-flight checks want this in one place.

✅

Cruise Speed / Altitude Check

Highlight in amber/red if the aircraft's current Mach or altitude significantly deviates from the OFP planned cruise values. Simple compliance check for VA auditors.

📬

Position Report History

A log of all position reports submitted this flight with timestamps. Shows "sent" vs "pending" status so you can see what the backend received.

🤖

Automatic Position Reporting

Auto-submit position reports to the Aviates backend at configurable intervals (e.g. every 10 mins) while airborne. The manual submit button stays too.

💨

Wind Component Display

Calculate and show headwind/tailwind component and crosswind from SimConnect wind data. Useful during approach, and looks very professional in cruise.

⚠️

NOTAM Section from OFP

Parse and display relevant NOTAMs included in the SimBrief OFP. Collapsible section below METAR. VA pilots are expected to review these pre-flight.
